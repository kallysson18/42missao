# Missão - Lógica de Programação (Python)

Este repositório contém os exercícios desenvolvidos durante a Missão de Lógica de Programação utilizando Python, com foco no aprendizado dos fundamentos da programação.

## 📚 Objetivo

O objetivo deste repositório é desenvolver raciocínio lógico e base de programação através da resolução de exercícios práticos.

Durante os estudos foram abordados conceitos como:

- Variáveis e tipos de dados
- Estruturas condicionais (if / else)
- Estruturas de repetição (for / while)
- Listas e manipulação de dados
- Criação de algoritmos simples
- Resolução de problemas

## 🧠 Linguagem utilizada

- Python

## 📁 Organização

Os exercícios estão organizados por módulos, conforme o progresso do curso .
